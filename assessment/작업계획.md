`2026학년도 5학년 1학기 과정중심 평가 계획.hwpx`의 한글 문서 양식과 편집 구조를 기준으로, 현재의 2학기 평가 자료를 같은 형식의 문서로 정비한다.

따라서 이번 작업의 기본 범위는 위 여섯 과목으로 한다. 국어·도덕·과학·체육·창의적 체험활동까지 포함한 학교 전체 2학기 평가계획이 필요하다면 해당 과목 원고를 별도로 받아 추가해야 한다.

## 3. 1학기 양식에서 반드시 유지할 구조

1학기 문서의 다음 구조를 2학기에도 유지한다.

1. 표지
   - `2026학년도 과정 중심 평가 계획`
   - `5학년 2학기`
   - `장량초등학교`
2. 과목별 `교수학습 및 평가 운영계획` 표
3. 과목별 `수행평가 기준안`

과목별 운영계획 표의 열은 1학기와 동일하게 유지한다.

- 시기

현재 2학기 기준안에 이미 있는 메타데이터와 평가 기준을 이용해 이 요약표를 새로 작성한다. 기준안의 상세 표와 학생용 평가지 내용은 요약표와 연결되도록 배치한다.

## 4. 2학기 자료에서 확인된 내용 수정 대상

### 필수 수정

#### 미술 7단원 내용 혼입

`7. 먹과 색이 어우러진 우리 그림`은 수묵 담채화 표현 평가인데, 현재 예시 답안·채점기준·학생용 문항 일부가 수학 도형 평가 내용으로 되어 있다.

- `생활 속 대상에서 도형(수학)을 찾을 수 있는가?`
- 도형을 3개·2개·1개 찾았는지에 따른 점수
- 생활 속 도형의 연결 모양을 파악하는 문항

이 부분은 미술 7단원의 실제 평가요소인 먹과 색, 수묵 담채화 표현 방법, 농담·선의 변화 등에 맞는 문항과 채점기준으로 교체한다. 단순한 양식 복사로 끝내면 안 되는 핵심 내용 오류이다.

### 오탈자 및 표현 정비

- 사회 1단원 예시 답안: `무늬를 음악으로 세기고` → 문맥에 맞는 `무늬를 음각으로 새기고` 등으로 확인·수정
- 음악 3단원: `간심` → `관심`
- 음악 3단원: `더울 발전시킬` → `더욱 발전시킬`
- 과목명·단원명·평가시기의 띄어쓰기와 표기 통일
- 1학기 사회 표에 남아 있는 `2025학년도`와 같은 이전 연도 표기는 2학기 문서에 복사하지 않고 `2026학년도 2학기`로 통일

## 5. 한글 파일 기술 요구사항

### HWPX를 기준 템플릿으로 사용

1학기 양식을 지키려면 새 문서를 DOCX나 일반 텍스트에서 다시 만드는 방식보다, 1학기 HWPX를 기준 템플릿으로 복제하고 내용만 교체하는 방식이 안전하다.

HWPX는 ZIP 컨테이너 안에 HWPML XML과 리소스가 들어 있는 형식이다. 다음 구성요소를 임의로 삭제하거나 재생성하지 않는다.

- `Contents/header.xml`: 글꼴·스타일·문서 기본 설정
- `Contents/section0.xml`: 본문·표·문단·쪽 나눔·컨트롤
- `Contents/content.hpf`: 패키지 내 본문 및 리소스 관계
- `settings.xml`, `version.xml`
- `META-INF/manifest.xml`, `META-INF/container.xml`
- `BinData/`: 삽입 이미지 및 미리보기 리소스

### 표 구조 보존

1학기 양식의 표는 병합 셀, 고정 열 너비, 행 높이, 테두리, 셀 안쪽 여백, 세로 정렬이 핵심이다. XML을 수정할 때 다음을 보존한다.

- 행·열 수
- 병합 셀의 행·열 범위 및 주소
- 셀 너비·행 높이
- 테두리 굵기와 색상
- 셀 배경색
- 문단 정렬·줄 간격·들여쓰기
- 평가 기준 A/B/C의 행 구조
- 학생용 평가지의 답안 영역과 체크 영역

특히 운영계획 표의 헤더 병합과 수행평가 기준안의 메타데이터 표를 새로 만들 때, 단순히 `|` 문자로 표를 재현하지 않고 HWPML의 실제 표·셀 구조를 사용해야 한다.

### 서식·리소스 보존

- 기존 스타일 ID와 글꼴 설정을 우선 재사용한다.
- 한글 글꼴과 문자 인코딩은 UTF-8 기반 HWPML 상태를 유지한다.
- 쪽 나눔은 빈 줄을 반복해 맞추지 말고 기존 문서의 페이지·구역 컨트롤을 유지한다.
- 머리말·꼬리말·쪽번호는 기존 구역 설정을 복제한다.
- 삽입 그림은 `BinData` 파일과 XML의 참조 ID를 함께 관리한다.
- HWP 레거시 파일은 OLE 바이너리이므로 XML 정규식으로 직접 수정하지 않는다. 필요한 경우 한글에서 HWPX로 변환한 뒤 작업용 템플릿으로 사용한다.

### 검증 기술

수정 후에는 다음 순서로 검증한다.

1. HWPX ZIP 압축 구조가 정상적으로 열리는지 확인
2. `section0.xml`이 정상 XML이고 필수 네임스페이스가 유지되는지 확인
3. 한글에서 열어 표·글꼴·쪽번호·병합 셀을 확인
4. PDF로 내보내 전체 페이지를 렌더링하여 표 잘림·겹침·빈 페이지·깨진 한글이 없는지 확인
5. 운영계획 요약표와 각 수행평가 기준안의 단원명·시기·성취기준·평가기준이 일치하는지 대조
6. 문서 안에 이전 학기·이전 연도 표기가 남아 있지 않은지 검색

한글 프로그램 또는 HWPX를 정확히 재저장할 수 있는 도구가 없는 환경에서는 XML 직접 수정만으로 최종 품질을 보증하지 않는다. 최종본은 한글에서 열고 다시 저장한 뒤 PDF 렌더링까지 확인하는 것을 원칙으로 한다.

## 6. 실제 수정 순서

1. 1학기 HWPX의 표지·구역·스타일·페이지 구성을 복제한다.
2. 표지와 문서 제목을 `2026학년도 5학년 2학기`로 변경한다.
3. 사회·수학·실과·음악·미술·영어의 운영계획 요약표를 생성한다.
4. 각 요약표 뒤에 해당 과목의 2학기 수행평가 기준안과 학생용 평가지 묶음을 배치한다.
5. 미술 7단원의 수학 도형 내용 혼입을 미술 평가 내용으로 교체한다.
6. 오탈자·연도·띄어쓰기·단원명 표기를 정비한다.
7. 교육과정 운영계획·진도표와 평가시기를 교차 확인한다.
8. 한글 열기·재저장 및 PDF 렌더링으로 시각 검수한다.
